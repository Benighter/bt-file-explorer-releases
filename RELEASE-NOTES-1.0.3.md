# BT File Explorer 1.0.3

- Mark and unmark files without jumping to the top of the folder.
- Keep your place when using Select All, Invert Selection, Back, Copy or Cut.
- Selection updates the existing rows, keeping file previews and the current view in place.

Includes the features from 1.0.2. This is a directly distributed Android preview; Google Play submission remains pending Bennet's review.
