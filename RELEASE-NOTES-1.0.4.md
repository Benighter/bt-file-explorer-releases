# BT File Explorer 1.0.4

- Keep your place when opening files or returning from folders, including Back and breadcrumbs.
- Remember positions across tabs and screen recreation in all nine views.
- Access external Android/data and Android/obb with an explicitly authorized Shizuku connection.
- Use previews, copy/move/rename, recycle/restore, external opening and BT editor saves in those folders.
- See the real All files and media permission status in Settings → Storage access.

Shizuku needs to be started again after restarting your phone. Some MediaTek phones require the official Shizuku 13.5.4 release because 13.6 has a known service-startup fault. Private internal app and system files still require root access.

Includes the previous selection, default-app, theme and automatic-update improvements. Google Play submission remains deferred until Bennet approves the preview.
