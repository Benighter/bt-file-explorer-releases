# BT File Explorer 1.0.2

- Open files in your chosen Android default apps, including PDF and Word viewers.
- Choose nine icon, list and detail layouts in folders and Apps, with visual view and sort controls.
- Enjoy clearer text, undistorted icons, installed-app artwork and image, video, APK and PDF previews.
- Preview all four included themes before applying them. Settings now have meaningful icons.
- Return using the top Home button, reveal hidden files immediately, and turn the Recycle Bin on or off.
- Check for updates on opening or from Settings. Automatic downloads show progress and verify the package before Android asks you to install.

This is a directly distributed Android preview. No Google Play submission is included. External SMB/SFTP/FTPS accounts, real cloud accounts and DLNA renderers still need testing with available endpoints. Android controls access to protected app and system folders.
